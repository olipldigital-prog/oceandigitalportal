Cloud Backend & Project Settings

The Google Apps Script deployment is the cloud backend. All projects share one database; use the project location field to separate sites across Tamil Nadu and other states.

Cloud data is stored in the Google Sheet linked to your Apps Script project. Restrict spreadsheet and Drive access to authorised administrators. The portal does not use Aadhaar for authentication.
